Core Platform Architecture

Nine specialized forensic engines power Spectra's intelligence pipelines.

Intelligence Inspector

Cleans, strips, and formats unstructured logs. Automatically standardizes account names, IDs, serials, and dates with custom Discord markdown styling and hotkey macros.

Command Matrix

Translates sanitized account lists into exact server commands (/ban and /unban). Features quick preset chips, custom duration overrides, and a sequential copy queue with visual progress indicators.

Threat Heuristics

Intelligent pattern classification for main vs. twink accounts (M/T), hardware/software serial linking, age-based ranking, and real-time griefer violation alerts.

Forensic Visual Diff

Side-by-side and unified delta comparator. Detects newly registered twinks, departed accounts, identity mutations (renamed players), and escalating griefer flags across snapshots and raw dumps.

Network Alt Graph

Interactive 60 FPS Canvas physics visualizer. Graphically clusters main accounts with their known twinks and griefers, features interactive player dossiers, and instant ban command synthesis.

Server Rulebook & Ban Matrix

Configurable server rule profiles (RP Server, FiveM, Custom) with real-time command syntax preview. Synchronizes directly with the workspace command matrix and security audit blacklist.

Sandboxed Workspaces

Create, rename, and archive isolated workspaces. All state is partitioned locally in browser storage with single-click JSON backup export and AES-256 encrypted staff sync.

Mobile-First Architecture

Engineered for smartphones and desktop alike. Features dedicated slide-out drawer navigation, segmented tab switchers, and momentum touch scrolling on toolbars.

Zero Telemetry Privacy

100% offline-ready client execution. No logs, credentials, or audit trails ever leave your local device. Zero remote analytics, tracking, or external server calls.
